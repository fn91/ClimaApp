

🌤️ Nuevo Proyecto Front-End: App del Clima

Hoy quiero compartir mi App del Clima interactiva, desarrollada con HTML, CSS y JavaScript (ES6+) ☁️

Qué hace

Consulta el clima actual y el pronóstico de las próximas 24 horas usando la API de OpenWeather.

Incluye modo claro / oscuro persistente, geolocalización, y mensajes dinámicos con animaciones suaves.

Diseño responsive y moderno con estilo glassmorphism + gradientes.

Aprendizajes

Durante el desarrollo practiqué:

Consumo de APIs y manejo de asincronía (async/await)

UX visual y diseño accesible

Buenas prácticas de JavaScript moderno y organización modular
